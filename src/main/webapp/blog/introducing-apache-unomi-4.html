Introducing Apache Unomi 4

A major Customer Data Platform release — multi-tenancy, OpenSearch, and a larger test suite on the runtime Unomi 3 already shipped.

Apache Unomi 4.0 is a major open-source CDP release. It keeps the production runtime that shipped in Unomi 3.0 and continued through 3.1.0 — Java 17+, Apache Karaf 4.4, the Elasticsearch 9 Java API client, and persistence-based clustering — and adds a platform-wide multi-tenancy refactor, OpenSearch as a peer backend, cluster-aware tasks, safer validation, and stronger tests.

The 4.0.0 distribution updates the pins on that runtime: Karaf 4.4.12 (3.0.0 through 3.1.0 used 4.4.8) and Elasticsearch 9.4.3 (3.x used 9.1.3). OpenSearch support is new in 4.0 and is pinned to OpenSearch 3.7.0.

A strong second theme: Unomi 4 is also built for AI agents that need real customer memory (retrieve, store, summarize, segment) over a stable open API. See Unomi 4 for AI agents.

The familiar REST map stays put: all 119 documented Unomi 2.x OpenAPI paths are still present in 4.0, with new endpoints added alongside. Optional REST compatibility mode lets you phase Unomi 2.x and 3.x clients onto tenant API keys. Details in Migrating to Unomi 4.

The Unomi 4 journey

By the numbers (3.0.1 to 4.0)

  • Tests outpaced implementation: test Java ~12k at 3.0.1 → ~63k at 4.0, while production Java grew ~71k → ~118k (about 1.7×). Unomi 3.0.1 was still close in size to 2.7; the growth is the 3 to 4 step.
  • Test/main Java ratio ~0.17 → ~0.53
  • About 1,148 unit @Test methods and 388 integration @Test methods on 4.0
  • API stability: 119 / 119 OpenAPI paths retained in 4.0; +12 additive paths
  • Unit tests, not only ITs: new in-memory PersistenceService harness for fast, independent service tests

What’s in the box

  • Runtime, from Unomi 3 and updated in 4.0: Java 17+, Karaf 4.4.12, Elasticsearch 9.4.3, persistence clustering
  • New in 4.0: multi-tenancy and API keys, OpenSearch 3.7.0, the task scheduler, condition validation, and request tracing
  • Upgrade bridge: REST compatibility mode for phased Unomi 2.x and 3.x client migration
  • Docs: migration and upgrade runbooks in the official manual
